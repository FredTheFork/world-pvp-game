# Generated Cesium arena scene

`Phase1_GoogleWorld.unity` is the Phase 1 Cesium foundation extended for the metre-based arena, browser UGS sessions, and Phase 5 first-person locomotion. It is generated by the Unity Editor after package import. If it is missing or movement/camera/HUD wiring changes, use **Tools → World PvP → Phase 5 → Build or Rebuild Scene**. The generator writes the scene into this folder and registers it in Build Settings. Rebuilding replaces generated scene content; preserve custom edits first.
